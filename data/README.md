# Data and provenance

This directory is for compact numerical inputs needed to reproduce examples in the associated paper.

Each data file should have a documented provenance. In particular, values reconstructed from published figures should identify:

1. the original publication or patent;
2. the figure/table from which each quantity was obtained;
3. whether the value was read directly, reconstructed, normalized, or angle-aligned; and
4. any assumptions made during reconstruction.

Do not place third-party PDFs, figures, or other copyrighted source material in this directory unless redistribution is clearly permitted.
